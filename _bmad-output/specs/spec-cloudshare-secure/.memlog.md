topic: CloudShare Secure File Sharing Platform
updated: 2026-08-28T01:58
---

- (decision) Project goal: Build serverless secure file sharing platform with completion-based auto-deletion when all recipients have accessed the file.
- (capability) CAP-1: User can upload a file and assign recipient email addresses to initiate secure sharing.
- (capability) CAP-2: Recipient can access and download their shared file via a unique signed access link.
- (capability) CAP-3: System automatically purges files and metadata once all designated recipients have accessed their download link.
- (capability) CAP-4: Authenticated uploader can view file access progress and revoke/delete files early.
- (constraint) S3 bucket has public access blocked; all transfers must use short-lived presigned URLs.
- (constraint) Access links must be cryptographically signed per-recipient to prevent link forwarding or unauthorized access logging.
- (constraint) Frontend must never connect to AWS directly; backend and scheduled Lambda hold isolated IAM credentials.
